# Project template

The format for ACU projects. The Linear project template mirrors this file;
change both together.

Fields: a name that states the outcome, a one-sentence summary, a lead, the
initiative it serves, and a target date when one exists.

```markdown
## Outcome
<What is true when this project is done, in one or two sentences.>

## Why
<The problem and the evidence for it: numbers, calls, or reports.>

## Done when
- <A checkable result: a number, a behavior, or a record anyone can look up>
- <...>

## Out of scope
- <Nearby work this project will not do>

## Repos
<The repositories the work touches.>
```

## Rules

- The issues in the project are the work list. Do not copy them into the
  description; Linear lists them.
- Every "Done when" line is checkable by someone who was not in the room.
- A project ends. Standing work belongs in `Maintenance`.
