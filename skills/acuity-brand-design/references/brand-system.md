# Acuity Health visual system

## Brand idea

Acuity turns advancing AI into dependable healthcare labor. The visual system should express disciplined intelligence becoming useful work.

The desired feeling is:

- Minimal, not empty
- Intelligent, not academic
- Confident, not loud
- Human, not soft
- Provocative, not gimmicky
- Operational, not technical for its own sake

## Core visual principle

Make the argument visible.

Begin with the message, then find the smallest visual transformation that expresses it. Examples include:

- A rigid grid becoming an adaptive network
- Disconnected points becoming coordinated flow
- Noise becoming an ordered path
- Repetition becoming resolution
- Fragmented systems becoming one operating layer

Use one transformation per piece.

## Color

Primary palette:

- Ink black: `#080808`
- Warm paper: `#F4F2ED`
- Canvas gray: `#EEEEEB`
- Muted gray: `#81817B`
- White: `#FFFFFF`

Default to monochrome. Introduce an accent color only when the content requires semantic distinction, not decoration.

Avoid conventional healthcare blue and conventional AI purple as default brand colors.

## Typography

Use typography as structure, not decoration.

For thesis-led social graphics:

- Use a bold modern grotesk sans serif.
- Set type large enough to become the image.
- Prefer compact line breaks and hard contrast.
- Use uppercase selectively when conviction helps.

For long-form editorial work:

- Pair a restrained serif headline with a clean sans-serif body.
- Use serif type for mission, vision, or conceptual statements.
- Use sans-serif type for operating details, labels, and evidence.

For interfaces:

- Use a single clear sans-serif family.
- Prefer direct labels, visible state, and quiet hierarchy.

Avoid novelty typefaces, thin futuristic fonts, overly rounded startup typography, and more than two type families.

## Composition

- Use generous negative space.
- Prefer asymmetric editorial balance.
- Anchor content to a clear grid.
- Let one block of type dominate.
- Use small metadata, rules, or restrained footer branding to create document-like authority.
- Keep the brand mark secondary to the idea.
- Allow slight paper grain or print texture to counterbalance the precision of the geometry.

Do not fill every available area. Empty space should make the message feel deliberate.

## The seven-dot language

The official mark contains exactly seven dots:

1. One top-center dot
2. Two upper-side dots
3. One center dot
4. Two lower-side dots
5. One bottom-center dot

Use `../assets/acuity-health-mark.png` as the source of truth.

The mark suggests coordination, routing, connection, and one operating system. Abstract graphics may echo its geometry through nodes and paths, but those graphics must not masquerade as the official logo.

Never:

- Change the dot count
- Stretch the formation
- Add gradients or effects
- Turn the mark into a character
- Ask an image model to reproduce it from memory

## Photography and illustration

Use imagery only when it adds meaning that typography and geometry cannot.

If people appear:

- Favor candid, grounded, operational moments.
- Show dignity, concentration, or human connection.
- Avoid performative smiles and generic clinical staging.

If using illustration:

- Favor abstract editorial systems and simple geometry.
- Keep the material treatment tactile and restrained.
- Avoid literal robots and science-fiction symbolism.

## Copy inside visuals

Use one strong claim. Keep supporting explanation in the caption or document body.

Good structures:

- `NOT SOFTWARE TO INSTALL. LABOR TO DELEGATE.`
- `THE PRACTICE GOVERNS THE JOB. ACUITY MANAGES THE WORKER.`
- `AI HANDLES THE VOLUME. HUMANS ELEVATE THE CARE.`

Do not reuse these automatically. Derive the shortest accurate line from the current content.

## Format guidance

### LinkedIn

- Prefer square or 4:5.
- Optimize for phone legibility.
- Use 5–12 words in the image.
- Let the caption carry the full argument.
- Choose a frame that remains recognizable without reading small text.

### Presentations

- One argument per slide.
- Use large editorial headlines and sparse evidence.
- Keep charts monochrome unless color encodes meaning.
- Use the dot language to show coordination or flow.

### Documents

- Use a paper-like canvas, generous margins, serif conceptual headings, and sans-serif operating detail.
- Favor strong section rules and compact metadata over decorative page furniture.

### Websites

- Use the same editorial conviction with more restraint.
- Let operational proof and product behavior interrupt the conceptual typography.
- Avoid turning every section into a rounded card.

## Generation prompt foundation

For AI-generated raster work, adapt this foundation:

```text
Create a premium Acuity Health editorial visual.
Style: Swiss editorial design, restrained healthcare technology, black ink on warm uncoated paper, subtle grain, generous negative space, bold modern grotesk typography.
Concept: express one clear transformation from fragmented software or complexity into coordinated useful work using abstract grids, nodes, or flows.
Avoid: robots, humanoid AI, glowing brains, circuit imagery, blue-purple gradients, stock healthcare imagery, medical crosses, clutter, extra text, and watermarks.
```

Add the exact copy, format, composition, and constraints required by the task. Generate without the logo unless the tool can place the supplied asset exactly.

## Reference interpretation

`../assets/acuity-ai-labor-poster.png` is a style reference, not a rigid template.

Preserve its principles:

- Bold typographic conviction
- Warm monochrome materiality
- A single systems metaphor
- Strong negative space
- Quiet branding

Vary the layout and metaphor so future work forms a coherent family rather than repeating one poster.
