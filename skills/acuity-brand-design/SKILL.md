# Acuity Brand Design

Create work that feels unmistakably Acuity: minimal, confident, intelligent, human, and slightly provocative. Avoid generic healthcare and generic AI aesthetics.

## Start with the reference

Read [references/brand-system.md](references/brand-system.md) before designing.

Use these assets:

- `assets/acuity-health-mark.png`: exact seven-dot brand mark
- `assets/acuity-ai-labor-poster.png`: approved style reference

Never ask a generative model to redraw the logo. Place the exact asset when the production tool supports exact image placement. If it does not, omit the logo during generation and add it later with a tool that preserves the source pixels.

## Design workflow

1. Reduce the request to one idea the audience should understand immediately.
2. Choose one visual metaphor. Prefer systems becoming coordinated work: grids, nodes, flows, transitions, or structured movement.
3. Select the appropriate expression:
   - Use a typographic poster for a strong thesis or social post.
   - Use editorial hierarchy for documents and presentations.
   - Use restrained operational clarity for product and web interfaces.
4. Build around black, warm white, soft gray, strong type, and generous negative space.
5. Use the seven-dot geometry as a visual language without distorting or casually repeating the actual logo.
6. Validate the result at its real viewing size.

## Non-negotiables

- Make one idea dominant.
- Prefer a few large elements over many small ones.
- Keep social-image copy short, usually 5–12 words.
- Render user-supplied text exactly.
- Treat typography as the primary visual element when the message is conceptual.
- Keep the logo small and quiet; the idea should lead.
- Preserve a calm, human material quality through warm paper, subtle grain, or restrained texture.
- Use claims that can be defended. Do not turn visual confidence into unsupported marketing language.

## Avoid

- Humanoid robots, glowing brains, circuit-board faces, or chrome androids
- Blue or purple AI gradients, neon glows, and glossy futuristic effects
- Stock doctors, handshakes, headsets, hospital corridors, or medical crosses
- Decorative dashboards, floating UI cards, or meaningless data
- Busy infographics, excessive icons, centered corporate layouts, or rounded-card clutter
- More than one visual metaphor
- Redrawing, warping, recoloring, or adding dots to the logo

## Quality check

Before delivery, confirm:

- The message is understood in under three seconds.
- The design remains legible on a phone.
- The hierarchy has one obvious entry point.
- The piece could not be mistaken for a generic AI or healthcare brand.
- The exact seven-dot mark is used, or the mark is intentionally absent.
- Every element supports the idea.
- Text is spelled correctly and contains no unintended copy.

For generated raster work, inspect the final image visually and iterate on one defect at a time. Save approved project assets outside temporary generation directories.
